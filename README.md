# E-Commerce Database Management System

## Overview

This project is a relational database designed for an e-commerce platform using Oracle SQL.

The objective is to build the database from the ground up by following database design principles, beginning with an Entity-Relationship (ER) model and gradually implementing the complete database system.

This project serves as a portfolio project while strengthening my understanding of database design, normalization, and Oracle SQL.

---

## Features

The current database models the core components of an e-commerce platform, including:

* User Management
* Seller Management
* Customer Management
* Product Catalog
* Product Categories
* Order Management
* Payment Records
* Delivery Tracking
